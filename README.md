# Virtual Embryo community projects

Smaller independent resources for the Virtual Embryo Challenge that are useful but not the two primary contributions.

## Projects

- **[ML Guide](ml-guide/)** — a bridge from standard ML to the challenge's population-generation, spatial, and perturbation problems.
- **[Data Safety Kit](data-safety/)** — a conservative helper for external-data stage/genotype rules and source disclosure.
- **[Metric Lens](metric-lens/)** — a small explainer for how public local `veckit` metrics map into weighted validation-board score contributions.

The two larger contributions live separately:

- **[Intuition Lab](https://github.com/i-habib/virtual-embryo-community/tree/main/intuition-lab)** — controlled scorer experiments for Tasks 1–3.
- **[External Data Catalog](https://github.com/i-habib/external-data-catalog)** — curated public sources, preprocessing adapters, provenance, and real-release validation.

These are independent community resources, not official challenge tools. The official challenge rules and scorer remain the source of truth.
